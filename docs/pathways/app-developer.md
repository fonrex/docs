# 💻 Pathway: App Developer

This pathway is built for **Software, Web, and Mobile Developers** integrating the Fonrex API into applications (React, Vue, Node.js, Python, Go, Flutter, etc.).

> [!TIP]
> **Goal:** Perform optimized REST queries, subscribe to real-time WebSockets streams, and handle multi-provider fallbacks.

---

### ⏱️ Estimated Time: 10 minutes

---

## 📌 Step 1: API Exploration & Swagger UI

Fonrex provides an interactive OpenAPI / Swagger interface generated by FastAPI:
- `http://localhost:5000/docs` or `http://localhost:5000/redoc`

---

## 📌 Step 2: First REST API Request (Asset Search)

Search tickers or currency pairs via `/api/v1/assets/search`:

```typescript
// TypeScript / JavaScript example (fetch)
async function searchAssets(query: string) {
  const response = await fetch(`http://localhost:5000/api/v1/assets/search?q=${encodeURIComponent(query)}`);
  const data = await response.json();
  return data.results;
}

// Usage
searchAssets('Apple').then(results => console.log(results));
```

---

## 📌 Step 3: Realtime Data Streaming (WebSockets)

To display live quotes without polling server endpoints, subscribe to the Redis Pub/Sub WebSocket stream:

```javascript
const ws = new WebSocket('ws://localhost:5000/ws/v1/realtime');

ws.onopen = () => {
  console.log('⚡ Connected to Fonrex WebSocket');
  ws.send(JSON.stringify({
    action: 'subscribe',
    symbols: ['AAPL', 'TSLA']
  }));
};

ws.onmessage = (event) => {
  const priceUpdate = JSON.parse(event.data);
  console.log(`📈 Live price update for ${priceUpdate.symbol}: $${priceUpdate.price}`);
};
```

*(See the [Realtime Configuration Guide](/docs/guides/configure-realtime) for reconnection and multiplexing).*

---

## 📌 Step 4: Error Handling & Multi-Provider Fallback

Fonrex abstracts third-party API complexities. If the primary provider fails, the Fonrex fallback engine automatically serves secondary provider data with an HTTP `200 OK` and a diagnostic header.

```typescript
const res = await fetch('http://localhost:5000/api/v1/fundamentals/income-statement?symbol=AAPL');
const providerUsed = res.headers.get('X-Fonrex-Provider-Source');
console.log(`Data served by: ${providerUsed}`);
```
