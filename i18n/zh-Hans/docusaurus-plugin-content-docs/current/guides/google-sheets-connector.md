将 Google Sheets 连接至 Fonrex API，直接在电子表格中获取财务数据（基本面、DCF估值、技术指标）。

![Fonrex Sheets Connector 预览](/img/template-preview.png)

:::info
**本模板显示的数据仅供参考。**
:::

## 3 步安装指南

### 步骤 1 — 复制模板
👉 **[打开 Fonrex Sheets 模板](https://docs.google.com/spreadsheets/d/1PUBLISHED_TEMPLATE_ID_XYZ_1234567890/copy)**

### 步骤 2 — 配置 API 密钥
1. 在表格中点击 **Fonrex** 菜单
2. 点击 **Configure API Key**
3. 粘贴您的 API 密钥 (`frx_live_...`) 并确认。

### 步骤 3 — 添加股票代码
在 **Watchlist** 表格中添加代码（如 `AAPL`, `MSFT`）并手动刷新。
