Connectez votre document Google Sheets à l'API Fonrex pour récupérer des données financières (fondamentaux, valorisations DCF, indicateurs techniques) directement dans vos tableurs — sans écrire de code.

![Aperçu Fonrex Sheets Connector](/img/template-preview.png)

:::info
**Ce modèle affiche des données brutes à des fins d'information uniquement.**
:::

## Prérequis

- Un compte **Fonrex Relay** actif
- Une clé API au format `frx_live_...`
- Un compte Google

## Installation en 3 étapes

### Étape 1 — Copier le modèle

Cliquez sur le lien pour créer votre copie du modèle :
👉 **[Ouvrir le modèle Fonrex Sheets](https://docs.google.com/spreadsheets/d/1PUBLISHED_TEMPLATE_ID_XYZ_1234567890/copy)**

### Étape 2 — Configurer votre clé API

1. Dans votre copie du Sheet, cliquez sur le menu **Fonrex**
2. Cliquez sur **Configure API Key**
3. Collez votre clé API (`frx_live_...`) et validez.

### Étape 3 — Ajouter vos tickers

1. Ouvrez l'onglet **Watchlist**
2. Ajoutez vos symboles en colonne A (à partir de la ligne 2) : ex: `AAPL`, `AIR.PA`, `MSFT`
3. Lancez un rafraîchissement depuis le menu Fonrex.
